# MatheKompass

Digitale Lernbegleitung für Mathematik in den Jahrgangsstufen 5–7.

## Aktueller Stand
- `index.html`: Schülerstartseite mit Lernweg, Tipps, Übungsstudio und Lerncheck. Grundrechenaufgaben werden im Browser generiert.
- `materialstudio.html`: Vorbereitungswerkzeug für Lernschritte mit Aufgaben, zwei Hilfestufen, Lösungen, Zusatzübungen und Materiallinks.
- Das Materialstudio speichert Entwürfe **nur lokal im jeweiligen Browser**. Über JSON-Export können Materialien gesichert und später zentral eingespielt werden. Ein JSON-Import ist ebenfalls möglich.
- Noch **keine** geschützte Lehreranmeldung, keine zentrale Datenbank, kein PDF-Upload und keine automatische Veröffentlichung von Materialien.

## Nächste Schritte
1. Echte Lernwegelisten und Musterlösungen übernehmen.
2. Materialdateien im Schülerbereich nach Jahrgang, Thema und Niveau anzeigen.
3. Geschützte Rollenverwaltung und zentrale Materialverwaltung einrichten.
4. Kompetenzzuordnung und optionale KOMPASS-Anbindung.
5. Aufgabenformate über Grundrechenarten hinaus ausbauen.

Keine Schülernamen oder personenbezogenen Daten in öffentliche Repository-Dateien aufnehmen.
